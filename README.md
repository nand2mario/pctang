# IBM PC/XT core

This is a port of [PCXT_MiSTer](https://github.com/spark2k06/PCXT_MiSTer) to Sipeed TANG FPGA. Currently supports Tang Console 60K and 138K. 

What works: CGA video, floppy disks (A: and B:), keyboard (USB). PC-DOS 2.0. MS-DOS 3.31.

Not working yet: mouse, hard disks, sound cards.
